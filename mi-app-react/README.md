# Hola Mundo - React

## Stack elegido

- Frontend: React
- Herramienta: Vite

## Motivo de la elección

Elegí React porque:

1. Es uno de los frameworks más utilizados para el desarrollo de interfaces web.
2. Permite reutilizar componentes, facilitando el mantenimiento del código.
3. Tiene una gran comunidad y amplia documentación.
4. Es una tecnología muy demandada en el mercado laboral, por lo que es útil para mi formación profesional.
